# 🤖 OperatorIQ

AI Operating System for Vending Operators

OperatorIQ is an AI-powered platform that helps vending machine operators monitor performance, analyze sales, optimize inventory, and automate daily operations.

🌐 Live Demo:
https://operator-iq-seven.vercel.app

---

# 🚀 Features

- AI Dashboard
- Inventory Management
- Financial Analytics
- AI Insights
- KPI Tracking
- Smart Reordering
- Multi-location Support
